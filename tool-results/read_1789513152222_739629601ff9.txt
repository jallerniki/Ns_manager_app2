     1→# Worklog — Tkani Product Manager Dashboard
     2→
     3→## Project Goal
     4→Build a fast, minimal, beautiful dashboard for managing WordPress (WooCommerce) products
     5→from nstkani.ru using JWT authentication.
     6→
     7→## API Discovery
     8→- Auth: `POST https://nstkani.ru/wp-json/jwt-auth/v1/token` → `{token, user_display_name, user_email}`
     9→- Products (WooCommerce): `GET/POST/PUT/DELETE /wc/v3/products` with `Authorization: Bearer {token}`
    10→- Categories: `GET /wc/v3/products/categories`
    11→- Media upload: `POST /wp/v2/media` (WP endpoint, JWT auth)
    12→- Product fields exposed by WC: id, name, slug, sku, price, regular_price, sale_price,
    13→  stock_status, manage_stock, stock_quantity, description, short_description, categories,
    14→  images (array of {id, src, name, alt}), meta_data (array of {id, key, value}), status, menu_order
    15→- Total products: 3654
    16→- Known meta field labels (from screenshots): БРЕНД, СТРАНА ПРОИЗВОДСТВА, СОСТАВ, ШИРИНА,
    17→  КУПОН, ОСТАТОК, МЕТРАЖ, ДЕФЕКТ
    18→
    19→## Design Direction
    20→- Light, airy, minimal interface. Neutral palette (zinc/stone) + violet accent.
    21→- Subtle borders, minimal shadows, generous whitespace.
    22→- Sticky header + sticky footer (footer pinned to bottom, pushed when content overflows).
    23→- Smooth micro-interactions via framer-motion.
    24→- Fast: TanStack Query caching, optimistic updates, debounce search.
